GlyphSentry

Look-alike glyphs never slip past the guard.

Marks letters outside the Latin script, mixed-script look-alikes and invisible Unicode controls inside messages. Email addresses, URLs and domain names are always rendered in monospace so look-alike characters are easier to spot.

Detection mode

Colours

Deep red on a light red background stays readable in both light and dark themes.

Scripts to highlight

Latin (including Vietnamese diacritics such as ế, ộ, đ) is never highlighted.

Monospace

Address warnings

For the domain check the reference is the domain of the account that received the message (every identity of that account). Sub-domains count as internal. When no account domain is available — local folders, for example — the domain comparison is skipped, but the non-Latin check still runs.

Reset

The add-on never reads message sources, never uploads anything, and only touches the rendered message pane. Click the toolbar button to disable highlighting for the message that is currently open.
